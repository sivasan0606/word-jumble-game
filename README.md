Three Difficulty Levels — Simple (4-letter), Medium (6-letter), Complex (8-letter)
Multiple Choice Gameplay — Four options per jumbled word
Hint System — Reveal helpful hints anytime
Score Tracking — Earn +10 points per correct answer
Streak Rewards — 3 correct in a row triggers a 🎉 firecracker celebration
Smart Word Rotation — No repeats until all words are used
Responsive Design — Works on desktop and mobile
Zero Dependencies — Just open and play

✨ Features
Three Difficulty Levels
🟢 Simple – 4-letter words (bird, fish, tree, moon, etc.)
🟡 Medium – 6-letter words (banana, guitar, planet, etc.)
🔴 Complex – 8-letter words (elephant, computer, mountain, etc.)
Multiple Choice Gameplay – Four options per jumbled word for quick and engaging play
Hint System – Stuck? Reveal a helpful hint anytime without penalty
Score Tracking – Earn +10 points for every correct answer
Streak Rewards – Get 3 correct answers in a row to trigger a 🎉 firecracker celebration!
Smart Word Rotation – Words are tracked so you won't see repeats until all words in a difficulty have been used
Responsive Design – Clean, modern UI that works on desktop and mobile
Zero Dependencies – Just open the HTML file in any browser and play
🚀 Getting Started
Option 1: Direct Open
Simply double-click the index.html file to open it in your default web browser.
Option 2: Live Server (Recommended for Development)
bash
# Using VS Code Live Server extension
# OR using Python
python -m http.server 8000

# Then visit http://localhost:8000
Option 3: Deploy to GitHub Pages
Fork this repository
Go to Settings → Pages
Select branch main and folder / (root)
Your game will be live at https://yourusername.github.io/word-jumble-game
🎮 How to Play
Select a Difficulty – Click Simple, Medium, or Complex to choose your challenge level
Unscramble the Word – Look at the jumbled letters displayed on screen
Pick an Answer – Click one of the four multiple-choice options
Use Hints – Click "Show Hint" if you need a clue
Keep Playing – Click "Next Word" to continue and build your streak!
